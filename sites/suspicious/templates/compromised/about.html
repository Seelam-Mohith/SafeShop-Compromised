About ShopSafe Lab

ShopSafe Lab is the simulated, deliberately-compromised counterpart of the legitimate ShopSafe storefront. It mirrors the same visual design and fictional product data, but includes a set of clearly-labelled test routes used to generate controlled security evidence for the Watering-Hole Detection Laboratory.

All suspicious behavior is simulated, hard-coded, and restricted to this local machine. The application does not deploy malware, exploit vulnerabilities, collect credentials, or contact real external systems.
