Privacy Policy

ShopSafe Lab is a local cybersecurity laboratory application. It does not collect personal data and does not transmit any information outside this machine. The only data recorded is a structured access log of HTTP requests (path, method, status, timing, and the local client IP). Cookies, authorization headers, passwords, session tokens, request bodies, and query-string values are never logged.
